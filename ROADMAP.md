# FarmTree Native Roadmap

## Current Direction

The approved production website remains on the `farmtree` theme while a new
WordPress-native system is built in isolation.

| Phase | Task | Outcome |
|---|---|---|
| 1 | FT-NATIVE-001 | Block Theme, content ownership and editor foundation |
| 2 | FT-NATIVE-002 | Native homepage rebuilt with core blocks and patterns |
| 3 | FT-NATIVE-003 | Content models and non-technical admin experience |
| 4 | FT-NATIVE-004 | Real pages, navigation and clean URLs |
| 5 | FT-NATIVE-005 | Content migration, staging validation and cutover |
| 6 | FT-I18N-001 | English and Dutch architecture |
| 7 | FT-SEO-001 | Technical SEO foundation |
| 8 | FT-GEO-001 | Entity and generative-search architecture |
| 9 | FT-AEO-001 | Answer-oriented content architecture |
| 10 | FT-MOTION-001 | Restrained motion and interaction system |
| 11 | FT-AI-001 | FarmTree AI Assistant completion |

## Release Rule

The new theme remains inactive until FT-NATIVE-005 is complete and activation is
explicitly approved. The production `farmtree` theme remains the rollback theme.
