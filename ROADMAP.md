# FarmTree Native Roadmap

## Current Direction

The approved production website remains on the `farmtree` theme while a new
WordPress-native system is built in isolation.

| Phase | Task | Status | Outcome |
|---|---|---|---|
| 1 | FT-NATIVE-001 | Local foundation complete | Block Theme, content ownership and editor foundation |
| 2 | FT-NATIVE-002 | Local implementation complete | Native homepage rebuilt with core blocks and patterns; runtime validation pending |
| 3 | FT-NATIVE-003 | Planned | Content models and non-technical admin experience |
| 4 | FT-NATIVE-004 | Planned | Real pages, navigation and clean URLs |
| 5 | FT-NATIVE-005 | Planned | Content migration, final migrated-content runtime validation and cutover |
| 6 | FT-I18N-001 | Planned | English and Dutch architecture |
| 7 | FT-SEO-001 | Planned | Technical SEO foundation |
| 8 | FT-GEO-001 | Planned | Entity and generative-search architecture |
| 9 | FT-AEO-001 | Planned | Answer-oriented content architecture |
| 10 | FT-MOTION-001 | Planned | Restrained motion and interaction system |
| 11 | FT-AI-001 | Planned | FarmTree AI Assistant completion |

## Release Rule

The new theme remains inactive until FT-NATIVE-005 is complete and activation is
explicitly approved. The production `farmtree` theme remains the rollback theme.
