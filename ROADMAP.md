# FarmTree Native Roadmap

## Current Direction

The approved production website remains on the `farmtree` theme while a new
WordPress-native system is built in isolation.

| Phase | Task | Status | Outcome |
|---|---|---|---|
| 1 | FT-NATIVE-001 | Local foundation complete | Block Theme, content ownership and editor foundation |
| 2 | FT-NATIVE-002 | Local validation complete | Native homepage rebuilt with core blocks and patterns |
| 3 | FT-NATIVE-003 | Private-first local foundation complete | Customer-segment model/template, private source entries and editorial drafts; broader admin work remains |
| 4 | FT-NATIVE-004 | Planned | Real pages, navigation and clean URLs |
| 5 | FT-NATIVE-005 | Planned | Content migration, final migrated-content runtime validation and cutover |
| 6 | FT-I18N-001 | Planned | English and Dutch architecture |
| 7 | FT-SEO-001 | Local foundation complete | Description, canonical ownership, noindex gate and unpublished-locale policy |
| 8 | FT-GEO-001 | Local foundation complete | Organization/WebSite entity graph and audience semantics |
| 9 | FT-AEO-001 | Local foundation complete | Visible direct-answer FAQ structure and matching schema |
| 10 | FT-MOTION-001 | Local implementation complete | Restrained progressive motion with reduced-motion support |
| 11 | FT-AI-001 | Safely gated | Existing server-side assistant remains inactive until a real provider is configured |

## Release Rule

The new theme remains inactive until FT-NATIVE-005 is complete and activation is
explicitly approved. The production `farmtree` theme remains the rollback theme.
