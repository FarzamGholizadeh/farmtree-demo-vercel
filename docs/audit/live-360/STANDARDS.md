# Reference baseline and assurance limits

Checked against primary publishers on 2026-09-19. These are engineering
references, not a certification claim. Full licensed ISO normative texts were
not supplied; catalogue abstracts do not prove clause-by-clause compliance.

| Reference | Application in this programme |
|---|---|
| [ISO/IEC25010:2023](https://committee.iso.org/standard/78176.html) | Product-quality categories and evidence coverage |
| [ISO/IEC/IEEE12207:2026](https://www.iso.org/standard/90219.html) | Source-to-release lifecycle; not obsolete2017 edition |
| [ISO9241-210:2019](https://www.iso.org/standard/77520.html) | Persona/task review; real user research remains separate |
| [WCAG2.2](https://www.w3.org/TR/WCAG22/) and [ISO40500:2025 adoption](https://www.w3.org/news/2025/web-content-accessibility-guidelines-wcag-2-2-approved-as-iso-iec-international-standard/) | AA criterion matrix, automated and manual evidence boundaries |
| [ISO27001:2022](https://www.iso.org/standard/27001) / [Amd1:2024](https://www.iso.org/standard/88435.html) | Risk-based security; organisational ISMS/climate-context evidence not inferred |
| [ISO27701:2025](https://www.iso.org/standard/27701) | Privacy data-flow/processing gaps; not organisational PIMS certification |
| [29119-1:2022](https://www.iso.org/obp/ui#iso:std:iso-iec-ieee:29119:-1:ed-2:v1:en), [2:2021](https://www.iso.org/standard/79428.html), [3:2021](https://www.iso.org/standard/79429.html), [4:2021](https://www.iso.org/standard/79430.html) | Test concepts/process, reproducible records and risk-based techniques |
| [OWASP ASVS](https://owasp.org/projects/asvs), stable5.0.0 | Scoped application-control review, not exhaustive penetration testing |
| [OWASP header guidance](https://cheatsheetseries.owasp.org/cheatsheets/HTTP_Headers_Cheat_Sheet.html) | Conservative nosniff/referrer defaults; HSTS/CSP need separate scope/compatibility decisions |
| [Google Search Essentials](https://developers.google.com/search/docs/essentials), [canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), [Schema.org](https://schema.org/) | Crawl, canonical ownership and truthful entity/article metadata |
| [Core Web Vitals](https://web.dev/articles/vitals) | LCP≤2.5s, INP≤200ms, CLS≤0.1; lab is not field evidence |

Runtime source changes cannot establish organisational controls, contractual
retention, testimonial permission or representative-user comprehension. Those
remain MANUAL-VERIFY/UNKNOWN until the relevant evidence exists.
